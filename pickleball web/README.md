# Cleveland High School Pickleball — $0 Website

This is a static website. It has no database, no paid plugins, and no required hosting subscription.

## Files
- `index.html` — the complete site
- `styles.css` — all styling
- `README.md` — these instructions

## First things to customize
1. In `index.html`, replace the Google Forms placeholder URL:
   `https://forms.google.com/`
   with your actual student interest form.
2. Replace the three `TBD` events with real dates.
3. Update the FAQ answers once club policies are finalized.
4. Add your official school/club logo when you have one.
5. Add real photographs once you have them.

## Free publishing
Recommended: GitHub Pages or Cloudflare Pages.

### GitHub Pages
1. Create a free GitHub account at github.com.
2. Create a new public repository, e.g. `cleveland-pickleball`.
3. Upload `index.html` and `styles.css`.
4. In the repository, open Settings → Pages.
5. Choose the main branch as the source and save.
6. GitHub will provide a free `github.io` website address.

### Cloudflare Pages
1. Create a free Cloudflare account.
2. Create a Pages project.
3. Upload this folder as a static site.
4. Cloudflare provides a free `pages.dev` address.

No custom domain is required. If you eventually want one, you can buy a domain separately.
